# Code of Conduct

We want this project to be a welcoming, professional place to collaborate.

Be respectful, constructive, and patient. Focus criticism on code and ideas, not people. Harassment, discrimination, threats, doxxing, and intentionally disruptive behavior are not acceptable in project spaces.

Maintainers may edit or remove content and temporarily or permanently restrict participation when behavior undermines a safe and productive community. Report conduct concerns privately to the maintainers through the repository owner's published contact channel.
